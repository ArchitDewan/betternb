# Quotient rule

## Method

For f(x) = u(x)/v(x), use f'(x) = (u'(x)v(x) - u(x)v'(x)) / v(x)^2 where v(x) is nonzero.

## Common mistake

Preserve the order in the numerator: derivative of the top times the bottom, minus the top times the derivative of the bottom.

## Example

For f(x) = x/(x+1), f'(x) = ((x+1)-x)/(x+1)^2 = 1/(x+1)^2.
